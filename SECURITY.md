# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in CrowdVibe, please report it responsibly.

**Do NOT open a public issue.**

Instead, email the maintainers directly with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge your report within 48 hours and aim to release a fix within 7 days for critical issues.

## Scope

- Authentication and session management
- Guest cookie security (HMAC signing)
- Data access controls (cross-session validation)
- Input validation and injection prevention
- API rate limiting
